
# EvoWorld

An artificial evolution simulator built with Python.

## Project Overview

EvoWorld is a 2D artificial ecosystem in which
digital organisms interact with their environment,
compete for resources, reproduce, and evolve.

## Technology

- Python 3
- Pygame
- NumPy
- Matplotlib
- pytest

## Project Structure

- simulation/: Simulation controller and world
- organisms/: Organisms, genetics and behavior
- environment/: Environment and food resources
- visualization/: Graphical interface
- analytics/: Simulation statistics
- tests/: Automated tests
- data/: Simulation data and saves
